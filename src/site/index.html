Mailflow

An Outlook add-in that turns a message's Received: headers into a delivery timeline — every server it passed through, and how long it waited at each one.

This page is just the host. The add-in itself only appears inside Outlook, on a received message.

Install for your whole tenant

  1. Microsoft 365 admin center → Settings → Integrated apps
  2. Upload custom apps, App type Office Add-in
  3. Provide link to manifest file → paste the URL above
  4. Assign users, then deploy. Test in Outlook on the web first — it updates in minutes, while the desktop ribbon can take up to 24 hours.

Install for just yourself

  1. Download the manifest to your machine. The sideload dialog no longer accepts a URL, only a file.
  2. Go to aka.ms/olksideload
  3. My add-ins → Add a custom add-in → Add from File
  4. Pick the manifest you just downloaded
Requests ReadItem permission only. Runs entirely in the task pane, makes no network calls, and has no backend — message content never leaves your client.
